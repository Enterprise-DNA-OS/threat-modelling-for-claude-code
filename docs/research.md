## Cost evidence

US$35,000 for a twelve-month platform contract including five threat models appears on the [IriusRisk vendor-sold AWS Marketplace offer](https://aws.amazon.com/marketplace/pp/prodview-lw45ujzidwkf2). This is a public offer, not a verified customer invoice. No specific NZ or AU customer's annual spend was confirmed in the available local records.

The [vendor plans page](https://www.iriusrisk.com/plans) offers a free Community edition and privately quoted Enterprise pricing based on model capacity, with unlimited Enterprise users. The comparison page therefore uses no numeric price, and does not imply the Enterprise plan is billed per seat. AWS Marketplace is supporting selection evidence, not a substituted direct list price.

## Product and export sources

- [IriusRisk plans](https://www.iriusrisk.com/plans): Community and Enterprise scope, full-model export and unlimited Enterprise users.
- [Vendor CLI](https://github.com/iriusrisk/iriusrisk-cli): OTM export with JSON format.
- [OTM specification](https://github.com/iriusrisk/OpenThreatModel): project, zones, components, flows, threats and mitigations. Its JSON schema uses destination where the README example uses target, so the importer supports both and rejects a conflict.
- [NIST SSDF](https://csrc.nist.gov/pubs/sp/800/218/final) and [OWASP process](https://community.owasp.org/Threat_Modeling_Process): design-review practices.

All code and fixtures are independently authored. No vendor library, proprietary data set or customer record is distributed. The page demonstrates actual outputs captured from the invented demo.
