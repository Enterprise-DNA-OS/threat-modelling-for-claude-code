# Why a database and an agent

The recurring jobs are evidence questions: which design changed, which boundary lacks an assessment, which mitigation has a test, and who owns the next decision. The database joins those records and the agent explains the result. Read-only HTML gives the team something to review or print.

An interactive screen gives drag-and-drop diagrams, browser collaboration and convenient navigation. This base has none of those, no mobile offline capture and no authenticated web portal. It does not continuously inspect code or cloud infrastructure. It does not generate threats from a proprietary library. The boundary register is a read-only record of the architecture the operator supplied.

Enterprise DNA can build screens, issue-tracker connections, access controls and report layouts around your version. Start by proving the review workflow and import with a security reviewer. Your data and rules remain yours.
