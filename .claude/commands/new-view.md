# Add a read-only design review

Read CLAUDE.md and views.json. Identify the question and its existing records. Add a view definition with read-only queries and an explanation of unknown values. Use brand.json and the shared rendering script. Run npm run view -- the-view-name. Open the generated HTML headlessly, inspect it and present the file. Do not add buttons, a server or write actions to a report.
